# 🤖 ربات معرفی تیم

ربات تلگرامی برای معرفی یک تیم فنی؛ ساخته‌شده با **Python** توسط **میلاد جعفری** به‌عنوان نمونه‌کار با ساختار ماژولار، جداسازی لایه‌ها و پوشش تست.

بعد از `/start` یک منوی دکمه‌ای باز می‌شود و بازدیدکننده بدون تایپ دستور اضافه، بین بخش‌های معرفی، اعضا، مهارت‌ها، نمونه‌کارها، راه‌های ارتباطی و امتیازدهی حرکت می‌کند.

---

## ✨ چه چیزهایی داخل ربات است

### 👥 معرفی گروه

یک صفحه خلاصه از اسم تیم، زمینه کاری، توضیح کوتاه، خدمات کلیدی و هدف. متن‌ها داخل `app/data/group.py` ذخیره شده‌اند و با ویرایش همان فایل، محتوای ربات عوض می‌شود.

### 👨‍💻 اعضای تیم

* فهرست اعضا با دکمه
* صفحه هر عضو با سمت، تخصص، بیوگرافی کوتاه و لینک‌ها
* دکمه قبلی / بعدی با شماره صفحه و چرخش حلقه‌ای
* لینک خالی (مثلاً لینکدین ثبت‌نشده) به‌صورت خودکار مخفی می‌ماند

اعضای نمایشی فعلی:

| عضو | نقش |
| --- | --- |
| میلاد جعفری | Backend Developer \| Python |
| کاربر نمونه | عضو نمایشی برای تست ورق زدن |

### 🛠 مهارت‌ها

مهارت‌ها بر اساس حوزه دسته‌بندی شده‌اند؛ هم می‌شود هر دسته را جدا دید و هم کل مهارت‌ها را یکجا.

دسته‌های فعلی:

* 🐍 Backend: پایتون، FastAPI، REST API، Pydantic ،SQLAlchemy ،Alembic ،Swagger ،JWT
* ✈️ Telegram Bot: ساخت ربات تجاری و اتوماسیون، اتصال به دیتابیس و API بیرونی، پنل مدیریت، FSM و میدلور
* 🧠 AI Agents: ایجنت هوشمند، وصل کردن LLM به API، ورک‌فلوهای هوشمند
* 🗄️ Database و زیرساخت: PostgreSQL ،Redis ،Celery، کش، Async و سرویس ایمیل
* 🐳 Docker: داکرایز کردن، Docker Compose، سرویس چندکانتینری، لینوکس و دیپلوی روی VPS
* 🧪 Quality: پای‌تست، GitHub Actions، گیت و گیت‌هاب، لاگ و مدیریت خطا

### 💼 نمونه‌کارها

* فهرست پروژه‌ها با دکمه
* صفحه هر پروژه با توضیح، تکنولوژی‌ها و لینک‌ها
* ورق زدن قبلی / بعدی مثل بخش اعضا
* دکمه GitHub ،Demo و Website فقط وقتی ساخته می‌شود که لینکش پر باشد

### 📞 ارتباط با تیم

آدرس ایمیل به‌صورت متن داخل پیام و بقیه مسیرها (تلگرام، گیت‌هاب، لینکدین، وب‌سایت) به‌صورت دکمه لینک نمایش داده می‌شوند.

### ⭐ امتیاز به تیم

بازدیدکننده از ۱ تا ۵ ستاره رأی می‌دهد و بر اساس امتیاز، یک پیام تشکر متفاوت دریافت می‌کند.

### 🔙 رفت‌وبرگشت

تمام صفحه‌های داخلی دکمه برگشت به منوی اصلی دارند. خطای پیش‌بینی‌نشده هم در هندلر سراسری ثبت می‌شود تا ربات از کار نیفتد.

│   ├── members.py        # اعضا

### منطق لایه‌ها

```text
Handler → Content Service → Data
```

هندلرها مستقیم سراغ `app.data` نمی‌روند؛ همه‌چیز از `app/services/content.py` عبور می‌کند. اگر بعداً دیتابیس یا پنل ادمین اضافه شود، فقط همین لایه عوض می‌شود.

## 🚀 اجرای سریع

### ۱. پیش‌نیازها

* Python 3.12
* توکن ربات از [@BotFather](https://t.me/BotFather)

### ۲. نصب

```bash
python -m venv .venv
source .venv/bin/activate  # ویندوز: .venv\Scripts\activate
pip install -r requirements-dev.txt
```

### ۳. ساخت فایل توکن

```bash
cp .env.example .env
```

داخل `.env` فقط این مقدار لازم است:

```env
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
```

### ۴. اجرا

```bash
python -m app.main
```

بعد در تلگرام دستور `‎/start` را به ربات بفرستید.

### 🐳 اجرا با داکر

```bash
docker compose up --build
```
